ALL 16 CONCEPTS - QUICK REFERENCE
================================================================================

[01] PROVIDER ABSTRACTION (src/llm/providers/base.provider.ts)
     Defines a uniform contract (`LLMProvider`). Application talks only to `LLMClient`,
     never directly to OpenAI/Gemini/Anthropic SDKs. Enables zero vendor lock-in.

[02] REQUEST VALIDATION (src/llm/validation.ts)
     Validates inputs before network calls via Zod (`LLMRequestSchema`). Rejects
     empty prompts or illegal parameters in <1ms without burning API credits.

[03] STRUCTURED OUTPUT (src/llm/structured-output.ts)
     Phase 1 parsing: safely wraps `JSON.parse()`. Traps hallucinated text, conversational
     prefixes, or broken syntax with typed domain errors.

[04] OUTPUT SCHEMA VALIDATION (src/llm/structured-output.ts)
     Phase 2 validation: parses raw JSON through Zod domain schemas (`LeadSchema`).
     Guarantees runtime data matches TypeScript types.

[05] TIMEOUTS & ABORT SIGNALS (src/llm/timeout.ts)
     Wraps attempts in `AbortController`. Prevents hanging promises and socket leaks
     by actively aborting underlying HTTP sockets when timers expire.

[06] TYPED ERRORS & RETRYABILITY (src/llm/errors.ts)
     Custom error taxonomy (`LLMError`, `LLMTimeoutError`, `LLMRateLimitError`,
     `LLMValidationError`). Tags errors with `retryable: boolean`.

[07] RETRY MECHANISM (src/llm/retry.ts)
     Automated loop re-executing transient failures. Converts a 95% single-call success
     rate into >99.8% availability without human intervention.

[08] EXPONENTIAL BACKOFF (src/llm/retry.ts)
     Calculates delay: `baseDelay * 2^(attempt - 1)` capped at `maxDelayMs`. Gives
     recovering upstream servers breathing room.

[09] JITTER (src/llm/retry.ts)
     Adds pseudo-random variation to backoffs: `Math.random() * cappedDelay`.
     Prevents the "Thundering Herd" problem by desynchronizing concurrent retries.

[10] OVERALL REQUEST DEADLINE (src/llm/retry.ts & client.ts)
     Hard global time budget (`totalTimeoutMs`) across all retries. Clamps attempt
     timeouts and fails fast before futile backoff sleeps.

[11] EXACT-MATCH CACHING (src/llm/cache/)
     Canonicalizes requests into SHA-256 keys. Returns cached responses in <1ms
     with zero incremental cost ($0.00).

[12] CIRCUIT BREAKER & PROVIDER FALLBACK (src/llm/circuit-breaker.ts & provider-router.ts)
     Maintains per-provider state machines (CLOSED/OPEN/HALF_OPEN). Routes traffic
     to backup providers on transient failures, but fails fast on validation errors.

[13] TRUSTED TOOL CALLING (src/llm/tools/)
     Sandboxed tool execution layer. Validates LLM-supplied arguments against Zod
     schemas before invoking internal functions.

[14] OBSERVABILITY & METRICS (src/llm/observability/)
     Pluggable Observer pattern decoupling telemetry from LLM code. Measures p50,
     p95, p99 latencies, token consumption, costs, retries, and fallbacks.

[15] EVALUATION & CI REGRESSION (src/llm/eval/ & src/eval-suite.ts)
     Measures output semantic quality against test datasets. Automated test suite
     fails the CI pipeline if accuracy regresses below predefined thresholds.

[16] 500-CALL RELIABILITY CHALLENGE (src/challenge.ts)
     Stress benchmark subjecting the gateway to 40% failure chaos across 500 requests.
     Proves 100% availability, bounded latencies (<100ms), and automated fallback.
